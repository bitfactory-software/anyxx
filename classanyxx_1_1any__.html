Detailed Description

template<is_proxy Proxy, template< typename... > typename Trait, typename... Args>
struct anyxx::any_< Proxy, Trait, Args >

The jacket to control dispatch for external polymorphism.

To control the behavior, any_ provides two template parameters: Proxy and Trait. Imagine this as a combination of a std::any_ and several std::functions.

With the Proxy template parameter, you control whether this any_ behaves like a copying function, a move-only function, a reference function, or if the target object is captured concretely inside of any_.

With the Trait template parameter, you specify the member functions of a captured object which can be invoked on this any_.

Template Parameters
ProxySpecifies the lifetime of the captured object. Any++ provides using_, cref, mutref, shared, weak, unique, and value. All Proxy classes must conform to the is_proxy concept.
TraitSpecifies the functionality of this any_. A class of this type is normally provided via a TRAIT macro. See there for examples. If the proxy is dynamic (i.e., type erased), the Trait must conform to the has_v_table concept (that means: must provide a v-Table).
Examples
21_Tree_any_borrow_as.cpp, 31_Animals_any_dispatch.cpp, X1_any_weak_const.cpp, _1_any_shape.cpp, _2c_trait_any_variant.cpp, _2d_trait_self.cpp, _2e_trait_algebra.cpp, _2f_trait_equal_comparable.cpp, _2p_trait_optional.cpp, _3_any_range.cpp, and _5_any_template.cpp.
