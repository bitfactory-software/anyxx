Detailed Description

template<typename R, typename... Args>
class anyxx::dispatch< R(Args...)>

Open dispatch method. Solves the expression problem.

Template Parameters
RThe return type.
ArgsThe parameter types. The signature of the dispatch is R(Args...).

The open dispatch is managed via a singleton object of this class.

To declare and define a singleton, use the ANY_SINGLETON and ANY_SINGLETON_DECLARE macros.

Each trait of the any_ tagged as virtual must have open dispatch enabled. To enable open dispatch, declare a struct named 'trait_name'_has_open_dispatch.

open dispatch evaluate, returns int, dispatched via an any<node>:

struct node_has_open_dispatch {};
TRAIT(node, dynamic_copyable, )
// open dispatch evaluate, returns int, dispatched via an
dispatch<int(virtual_<any<node>>>)> evaluate;
